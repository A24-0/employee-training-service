# Сервис обучения сотрудников

## Назначение
Приложение предназначено для автоматизации процессов корпоративного обучения и развития персонала. Оно решает проблему ручного учета прохождения тренингов, помогает HR-отделам и руководителям контролировать развитие навыков сотрудников, назначать обязательные программы обучения и отслеживать успеваемость в едином цифровом пространстве.

## Целевая аудитория
- **HR-менеджеры и специалисты по обучению (L&D):** для создания учебных программ, назначения курсов и аналитики.
- **Руководители подразделений:** для контроля компетенций своих подчиненных и планирования их развития.
- **Сотрудники компании:** для прохождения курсов, изучения материалов и сдачи итоговых тестирований.

## Предметная область
Предметная область охватывает сферу корпоративного управления человеческими ресурсами (HR Tech) и электронного обучения (e-Learning). Она включает в себя процессы планирования, организации, мониторинга и оценки образовательных мероприятий внутри компании, а также управление компетенциями и ролями персонала.

## Основные сущности
- **Администратор / Методист** — роль пользователей, которые создают, структурируют и наполняют учебные курсы и материалы.
- **Руководитель** — роль пользователей, которые назначают обучение своим подчиненным и отслеживают их прогресс и успеваемость.
- **Сотрудник (Обучаемый)** — роль пользователей, которые проходят назначенные курсы, изучают контент и сдают тесты.
- **Курс и учебные материалы** — объекты, содержащие образовательный контент (лекции, видео, статьи, презентации и т.п.).
- **Тестирование и прогресс** — объекты для проверки знаний, фиксации результатов и отслеживания статуса прохождения обучения.

## Основные функции
- Создание, редактирование и структурирование учебных курсов и материалов (для методистов и администраторов).
- Назначение обязательных и рекомендательных программ обучения отдельным сотрудникам или целым отделам (для руководителей и HR).
- Отслеживание прогресса прохождения курсов и автоматическая проверка результатов тестирований.
- Формирование аналитических отчетов по успеваемости сотрудников и общему охвату обучением.

## Возможности (ПР2)
- просмотр и поиск курсов, проверка длительности курса;
- добавление курсов и сотрудников;
- назначение курса сотруднику с проверкой повторного назначения;
- обновление прогресса прохождения курса и расчёт итогового статуса;
- отмена назначения курса;
- просмотр списка назначений.

## Структура проекта
- `main.py` — точка запуска и меню приложения;
- `courses.py` — работа с курсами;
- `employees.py` — работа с сотрудниками;
- `enrollments.py` — работа с назначениями курсов;
- `storage.py` — сохранение и загрузка данных (JSON);
- `utils.py` — вспомогательные функции безопасного ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования
- Python 3.x;
- pytest;
- flake8.

Установка зависимостей:
```
pip install -r requirements.txt
```

## Запуск программы
```
python main.py
```

## Запуск тестов
```
pytest
```

## Проверка качества кода
```
flake8
```
